Helix EducationView source on GitHub
Alpha learning engine

Learning records that can be replayed, inspected, and improved.

Helix Education is a standalone event-sourced learning-state engine with citation-grounded content, sealed assessment, adaptive paths, and portable progress history.

Current status: Alpha. Core engine implemented; gRPC service wiring and production integration remain pending.

What this project demonstrates

Event-sourced learning

Learning state can be reconstructed from its event history.

Grounded content

Generated material is designed around citations and inspectable sources.

Auditable progress

Assessment and milestones remain visible instead of becoming opaque scores.

Evidence before ambition

This project is presented with a clear boundary: what is implemented, what is experimental, and what still requires external validation. It is part of a local-first portfolio built by Hatem Ismail Shalaby.
