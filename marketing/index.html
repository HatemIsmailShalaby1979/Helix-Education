What Helix Is

A Self-Running AI Learning Engine

Event-Sourced Learning Records

Every interaction — lesson generated, quiz taken, answer evaluated, mastery achieved — is an immutable event. Replay any learner's journey from genesis. Audit trails aren't a feature; they're the foundation.

  • Event-sourced learning records, replayed from genesis
  • Complete event log: created, updated, archived
  • Exportable, portable, yours forever

Self-Running Content Pipeline

Enter a topic → Helix searches authoritative sources → generates ADHD-friendly lessons with citations → creates quizzes → evaluates with narrative feedback → records everything. No human in the loop required.

  • Grounded to authoritative web sources
  • ADHD-friendly micro-lessons with citations
  • Quizzes generated from source material
  • Narrative feedback, not just scores

Local LLM, No Vendor API

Runs on Ollama (qwen3:8b default) — fully local, no API keys, no rate limits, no pricing tiers. Your model, your hardware, your data. Swap models anytime.

  • Ollama local inference — no external API calls
  • Model-agnostic: qwen3, llama3, mistral, phi3, or any Ollama model
  • Grounded generation: LLM only writes lesson/quiz text; citations come from fetched sources
How It Actually Works

Where LLMs Are Used (And Where They're Not)

LLM Used

Lesson Generation

Ollama (qwen3:8b default) writes lesson sections grounded in fetched source chunks. LLM chooses which chunks to cite by index; citation text comes from trusted sources, never the LLM.

  • Prompt includes indexed source chunks
  • Output validated against Pydantic schema
  • Failed validation = hard error, no fallback
LLM Used

Quiz Generation

Same local LLM generates quiz questions from lesson content. Questions are grounded in the lesson text, not hallucinated.

  • Multiple choice + short answer
  • Difficulty calibrated to lesson level
  • Answer keys stored in sealed event store
No LLM

Web Grounding

Fetches authoritative sources via HTTP + BeautifulSoup. Zero LLM involvement. Pure deterministic extraction.

  • Search API → HTML → text extraction
  • Chunked for context window
  • Citations preserved end-to-end
No LLM

Metacognitive Dashboard

Pure event-sourced projection. Replays immutable event log to compute mastery, weak areas, retention curves, recommendations. Deterministic, auditable, no model inference.

  • Mastery from AnswerScoredEvent replay
  • Ebbinghaus forgetting curves per concept
  • Recommendations from knowledge map gaps
No LLM

Answer Evaluation

Short-answer scoring uses keyword overlap + semantic similarity against sealed answer keys — deterministic, no LLM judge.

  • AnswerKey stored at quiz creation
  • Scoring: required keywords + fuzzy match
  • Narrative feedback from template, not LLM
No LLM

Event Store & Persistence

Append-only JSONL event log. Every lesson, quiz, answer, session, recommendation — immutable. Replayable. Portable. Yours.

  • JSONL file or SQLite backend
  • No schema migrations — events are the schema
  • Export entire learner history as JSON

Where Learning Science Meets Engineering Discipline

Helix doesn't just deliver content — it makes the learning process visible, measurable, and optimizable. The metacognitive dashboard surfaces what's happening inside the learner's mind, not just what they clicked.

Mastery Tracking

Per-concept mastery thresholds with spaced repetition scheduling driven by pure functions — deterministic, reproducible, auditable.

Cognitive Load Monitoring

Real-time assessment of intrinsic, extraneous, and germane load. The system adapts difficulty to keep learners in the desirable difficulty zone.

Retention Analytics

Ebbinghaus forgetting curves modeled per learner, per concept. Predictive review scheduling that prevents decay before it happens.

Learning Path Optimization

Active recall, interleaving, and desirable difficulty — not as buzzwords, but as implemented cognitive science with measurable outcomes.

Operating Principles

  • Determinism over probability. Learning outcomes must be reproducible. Same inputs, same outcomes — every time.
  • Events over snapshots. State is derived, not stored. Every decision, every response, every milestone — an immutable fact.
  • Ownership over convenience. No API keys that expire. No models that deprecate. You deploy it. You own it. You control the entire stack.
  • Science over hype. Spaced repetition. Active recall. Interleaving. Desirable difficulty. These aren't features — they're cognitive science.
